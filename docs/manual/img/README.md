# Manual images

Screenshots for [MANUAL.md](../../MANUAL.md), grouped by area. They come from real games, mostly
with the game in Turkish: labels follow the game's language, names and numbers are illustrative.

| Folder | What |
|---|---|
| `start/` | status, world |
| `inbox/` | inbox, tasks, reply |
| `squad/` | squad views, contracts, health, doctor, progress, registration |
| `players/` | player page, search, career |
| `tactics/` | tactic, schedule, scouting, youth |
| `match/` | live panel, report, opponent |
| `league/` | table, fixtures, calendar, stages |
| `transfers/` | offer, contract, budget |
| `club/` | club, board, finances, staff, facilities, supporters, responsibilities |

New screenshots go in the folder of their area; update the link in `docs/MANUAL.md`.
